# 🚕 VIT CabConnect

### *Campus commutes, sorted.*

A full-stack ride-sharing platform built for VIT Vellore students — post a ride, find a group, split the fare.

---

## ✨ Why CabConnect?

Getting from campus to the airport, railway station, or a nearby city usually means either paying full cab fare solo or scrambling on WhatsApp groups to find others heading the same way. CabConnect fixes that — post a ride, let others join, chat with your group, and let the fare split itself.

## 🚀 Features

| | |
|---|---|
| 🔐 **Auth** | Secure login & sessions with JWT |
| 🛣️ **Ride Creation** | Post destination, date, time & seats available |
| 🙋 **Join Requests** | Browse open rides and request a seat |
| 💬 **Group Chat** | Real-time chat once your group is formed |
| 💰 **Auto Fare Split** | Fare calculated & divided automatically |

## 🛠️ Tech Stack

```
Backend   →  Node.js · Express
Database  →  SQLite
Auth      →  JWT
Frontend  →  HTML · CSS · JavaScript
```

## ⚡ Getting Started

```bash
git clone https://github.com/k-xur-i/vit-cabconnect.git
cd vit-cabconnect
npm install
npm start
```

> Check `server.js` for the port the app runs on locally.
